# BE201 Wi-Fi 与蓝牙工具包：使用与回退

这个目录每个版本都会重新生成，路径不变。工具包里有：
- Wi-Fi 驱动 `AirportItlwm.kext`。
- 蓝牙驱动 `BlueToolFixup.kext` 和 `IntelBTPatcher.kext`。蓝牙固件驱动 BE201BluetoothFirmware 不变，所以不在包里。

当前版本和它替换的上一版写在 `kit.json` 里。这一版改了什么，见 `开发与验证说明.md`。

## 安装

先挂载 macOS 同盘的 EFI 分区，然后在本目录运行：

```bash
python3 install.py --check
```

```bash
python3 install.py --install
```

- `--check`：只核对，并在本目录生成待写入的配置，不改 EFI。
- `--install`：先把整个 EFI 备份到 `EFI-backups/`，再写入。
  - 每个被替换的驱动都会改名为 `<名字>-recovery.kext`，作为恢复用的上一版。
  - 从 1.1.88 起，蓝牙和 Wi-Fi 的开关默认开启，安装时会从启动参数里去掉不再需要的那些。
  - config 只改三项：驱动备注、我们自己的启动参数和 TakeoffDelay。其余内容（包括音频会话的改动）原样保留。
  - 写入前会再比对一次 config；如果安装中途被别的会话改过，就停止，不写入。
  - 部署记录保存在 `deployments/`。

写入后重启生效。适用于 macOS Sequoia 15.2 及以后的版本。除 24G824 以外的版本，AWDL 默认不开启。

## Apple Watch 解锁

这个 Wi-Fi 驱动没有测距能力，Apple Watch 解锁需要跳过测距。用你自己的账户（不要加 sudo）双击 `Apple Watch跳过测距.command`，或者运行：

```bash
python3 install.py --watch-unlock
```

跳过测距以后，只剩蓝牙信号强度这一道检查，安全性比原来低。要恢复，运行：

```bash
python3 install.py --watch-unlock-undo
```

## 重启后

| 用途 | 双击 |
|---|---|
| 采集重启结果 | `采集重启结果.command` |
| ROC 实验（默认关闭，只在实验时打开） | `开始ROC实验.command` |
| 记录 15 分钟计数 | `开始记录.command` |
| 查看卡顿前后 90 秒 | `卡顿记录.command` |
| 抓包 | `开始抓包.command` |
| 采集手机日志 | `采集手机日志.command` |

这些工具生成的 `runtime-*.json`、`roc-*.txt`、日志和抓包都留在本目录。它们可能含有设备、网络和账号信息，只在本机使用，不要上传。

## 回退

把 EFI/OC 下对应的文件复制为 `EFI/OC/config.plist`，再重启：

| 情况 | 配置 |
|---|---|
| 三个驱动都回到上一版，启动参数也恢复原样 | `config-BE201-wifi-rollback.plist` |
| 保留当前驱动，关闭 AWDL | `config-BE201-wifi-off.plist`（加了 `be201_awdl_vif=0`） |
| 保留当前驱动，关闭全部 BE201 蓝牙补丁 | `config-BE201-wifi-btstock.plist`（加了 `-be201btstock`） |
| 只把机型改回 MacPro7,1 | `config-BE201-wifi-macpro.plist` |
| 禁用这张网卡的 Wi-Fi 驱动 | `config-BE201-wifi-WiFi-disabled.plist` |

这些配置按安装那一刻的 config 生成。之后如果别的会话又改了 config，需要按当时的 config 重新生成。

`python3 install.py --restore` 会用最近一次部署前的备份，恢复这次替换的驱动和 config。如果 EFI 在安装之后又被改过，它会拒绝执行。
