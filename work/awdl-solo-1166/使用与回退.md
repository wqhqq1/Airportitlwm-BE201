# 1.1.66：没连 Wi-Fi 时 AWDL 也能用

## 改了什么

- **第二信道到此为止：** 1.1.65 不开窗口也一样，第二个 MAC 在 149 上一帧都发不出去（模式 7、8 分别丢掉 173、154 帧），而在 149 上收帧一直正常。这块固件不支持一边连着路由器、一边在另一个信道上发送，第二信道的实验开关保留但不再使用。
- **新功能：没连任何 Wi-Fi 时 AWDL 独立运行（默认开启）：**
  - 以前驱动只有连上路由器才会建立 AWDL；没连网时整个 AWDL 不工作，隔空投送、通用控制都用不了。macOS 为了提速“暂时断开 Wi-Fi”时也一样。
  - 现在驱动空闲（没连网、也没在连接）5 秒后，会把 AWDL 单独放在 149 上运行。这时只有这一个信道在工作，帧走 AWDL 自己的队列。
  - 一开始连接 Wi-Fi，就先拆掉独立运行的 AWDL，连接过程和以前完全一样；连上后照常在路由器信道上运行。
  - 如果建立失败，这次开机就不再尝试，也不影响连上 Wi-Fi 之后的 AWDL。
- **其他修正：** 拆除 AWDL 时，停用链路的命令现在会带上链路真正所在的信道上下文，以前可能误带成路由器的。
- **其余不变：** 默认提速；路由器上的隔空投送靠手机到电脑的信道来，约 3 MB/s；手机热点上约 33 MB/s。

## 怎么用

不需要运行任何工具，正常使用就行：

- **没连网时：** 菜单栏 Wi-Fi 保持打开，但断开当前网络（或者在没有已知网络的地方）。过几秒后直接用隔空投送给 iPhone 发文件。
- **连上网络后：** 和以前一样使用。
- **出问题时：** 如果隔空投送不行，或者连 Wi-Fi 变得不正常，告诉我大概的时间和现象，我自己读日志。

## 回退

把 EFI/OC 下对应文件复制为 EFI/OC/config.plist，再重启：

| 情况 | 配置 |
|---|---|
| 回到 1.1.65 | `config-BE201-awdlsolo-rollback.plist` |
| 保留 1.1.66，关闭全部 AWDL 参数 | `config-BE201-awdlsolo-off.plist` |
| 只把机型改回 MacPro7,1 | `config-BE201-awdlsolo-macpro.plist` |
| 禁用这张网卡的 Wi-Fi 驱动 | `config-BE201-awdlsolo-WiFi-disabled.plist` |

只想关掉默认提速、其他不变：在终端运行 `sudo sysctl -w debug.be201_awdl_own_queue=0`，只对这次开机有效。

安装前的完整 EFI 备份在本目录 `EFI-before-install-*`。
