# 1.1.54：提速默认开启，研究第二信道

- **提速默认开启：** 1.1.53 测出的组合（专用队列、聚合和两个修正）现在开机后自动打开。在同一信道上（例如手机热点 149），电脑传手机从约 4.6 MB/s 提到约 33 MB/s。
- **第二次发送也能快：** 1.1.53 的一次传输结束后，最后几十帧没有发完，队列会一直被判定为“扣住”，同一次开机里再发就会退回慢速。这一版会在 3 秒后清掉这些帧并重建队列。
- **同时给 iPhone 和 iPad 发数据：** 专用队列要等当前对端空闲 1 秒后才会换到另一台设备，以免两边来回切换、丢帧。
- **第二信道（实验开关，默认关闭）：**
  - 自动选信道：电脑连在路由器的其他信道上时，自动用 AWDL 时间表里的 5GHz 信道，一般是 149。
  - 新的开窗口方式：按电脑自己公布的时间表开窗口，原来是跟着手机的时间表。
- **测试开关只在内存里：** 重启后第二信道恢复关闭。

## 测试

主要测第二信道，需要路由器：

1. 重启，电脑连路由器的 Wi-Fi，信道不是 149（最好是 36–48）。iPhone 解锁放在旁边，连它自己的网络。
2. 准备一个 3 GB 以上的大文件。
3. 双击“开始信道实验.command”。按提示开始用隔空投送发给手机，手机接受后按回车。
4. 工具测四段，每段 20 秒，共约 2 分钟：
   1. 只在路由器信道；
   2. 自动第二信道，不开窗口；
   3. 按手机时间表开窗口；
   4. 按自己时间表开窗口。

   每段记录传输速度、路由器延迟和到手机的延迟（相当于通用控制的卡顿程度）。
5. 最后回答文件有没有传完、哪一段明显变快或卡住。

如果方便，再在手机热点上验证一次默认提速：双击“开始隔空投送实验.command”，按提示先后发两个 1 GB 以上的文件。这个工具只记录，不改任何开关。

实验可能让 Wi-Fi 断开十几秒。如果卡死，长按电源键关机再开机，有 panic 文字先拍照。

## 回退

把 EFI/OC 下对应文件复制为 EFI/OC/config.plist，再重启：

| 情况 | 配置 |
|---|---|
| 回到 1.1.53，提速也关闭 | `config-BE201-awdlspeed-rollback.plist` |
| 保留 1.1.54，关闭全部 AWDL 参数 | `config-BE201-awdlspeed-off.plist` |
| 只把机型改回 MacPro7,1 | `config-BE201-awdlspeed-macpro.plist` |
| 禁用这张网卡的 Wi-Fi 驱动 | `config-BE201-awdlspeed-WiFi-disabled.plist` |

只想关掉默认提速、其他不变：在终端运行 `sudo sysctl -w debug.be201_awdl_own_queue=0`，只对这次开机有效。

安装前的完整 EFI 备份在本目录 `EFI-before-install-*`。
