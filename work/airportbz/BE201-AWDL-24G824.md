# BE201 / Sequoia AWDL development checkpoint

This is an offline foundation checkpoint, not an AWDL-capable release. The installed
1.1.0 Wi-Fi driver is unchanged. The successful Bluetooth 2.7.4 Handoff/text Clipboard
path is a separate result and does not prove AWDL data transport or Watch ranging.

Native 24G824 IO80211Family UUID: a763ca0b-fdb2-3b2f-a0b7-ad74c0a09ffd.
The compile-only fixture checks all 563 AWDL dispatch positions, 63 typed pure
handlers and all 522 inherited imports against this host's kernel symbols.
IO80211VirtualInterface/IO80211AWDLProtocol are 0x120 bytes. Native registration
returns IOReturn (zero is success); getSelfMacAddr returns its address in RAX,
not an ether_addr pointer. These declarations are corrected before lifecycle use.

The API92 MAC_CONFIG v2 command now represents both station client and P2P device
union members. Its length remains 52 bytes and the union offset remains 36.
The standalone preparation helper rejects unknown command versions, reserved
infrastructure/AUX IDs, unsupported actions and invalid unicast addresses.
REMOVE produces only the ID/action header with a zeroed payload. P2P discovery
extension stays disabled and the baseline accepts control/management frames.
There is no command send, resource reservation, capability publication or runtime
AWDL enablement in this helper. Its NIC ACK capability is supplied explicitly.
Linux v6.12 fw/api/mac-cfg.h and mvm/mld-mac.c are the wire-format references.

Validation:
- scripts/test-awdl-abi.py: native slots, object sizes, inherited native imports.
- scripts/test-p2p-mac.py: real header/helper, golden packet, unchanged station wire
  ABI, invalid-input buffer preservation, ASan/UBSan.
- Full 57-source command-line kernel build succeeds after the header changes.

Next hardware steps:
1. Own and release a non-infrastructure MAC ID under the firmware command gate.
   A timeout is an unknown firmware outcome, not proof the ID can be reused.
2. Bind a separate PHY/link and management TX queue, handle reset/sleep teardown,
   and keep NVM channel/power constraints. Data reception, unicast ACK behavior,
   peer stations and TX completions need separate qualification; a P2P management
   MAC alone is not an AWDL data interface.
3. Register the native virtual interface and queues after auditing ownership and
   callback semantics. Unsupported operations must remain explicit errors.
4. Connect bounded action/data RX, templates, synchronization/channel scheduling,
   IPv6 and Bonjour. Then test AirDrop; test Watch ranging independently.

No API is marked functional merely because its handler or interface exists.
