# 1.1.60：第二信道跟着时间表切换

- **1.1.59 的信道实验：** 打开第二信道之前，手机能看到电脑；打开以后看不到了，隔空投送一直“等待中”。系统给电脑排的时间表里，第 0 段在路由器的 36，手机是在这一段找到电脑的。原来的第二信道把 AWDL 整个搬到 149，第 0 段就没人在 36 上应答了。
- **1.1.60 新增模式 4（实验开关，默认关闭）：** AWDL 跟着自己的时间表切换，提前一个时段到位：149 的时段（第 2、10 段）去 149 并开窗口，第 0 段前回到路由器的 36。路由器上每个周期（约 1 秒）切换两次。
- **其余和 1.1.59 一样：** 默认提速，开机慢时 AWDL 不再失效。第二信道的所有模式都只在内存里，重启后恢复关闭。

## 测试

1. 重启后先确认隔空投送能正常发送（手机热点或路由器都可以）。如果发不出去，先关一次 Wi-Fi 再打开，让系统重新请求创建 AWDL 接口，然后告诉我。
2. 第二信道：电脑连路由器（信道不是 149，最好是 36–48），iPhone 解锁放在旁边，准备一个 3 GB 以上的文件。
3. 双击“开始信道实验.command”，按提示先用隔空投送发给手机（发不出去也保持发送窗口开着），再按回车。
4. 工具依次测四段：只在路由器信道 20 秒、模式 4 40 秒、模式 3 30 秒、关闭后 15 秒。每段结束时它会问你：手机分享面板能不能看到这台电脑，电脑上的传输有没有动。照实描述就行。
5. 结果每段都会保存，中途关掉窗口也不会丢；关掉窗口时第二信道会自动关闭。

实验可能让 Wi-Fi 断开十几秒。如果卡死，长按电源键关机再开机，有 panic 文字先拍照。

## 回退

把 EFI/OC 下对应文件复制为 EFI/OC/config.plist，再重启：

| 情况 | 配置 |
|---|---|
| 回到 1.1.59 | `config-BE201-awdlhome-rollback.plist` |
| 保留 1.1.60，关闭全部 AWDL 参数 | `config-BE201-awdlhome-off.plist` |
| 只把机型改回 MacPro7,1 | `config-BE201-awdlhome-macpro.plist` |
| 禁用这张网卡的 Wi-Fi 驱动 | `config-BE201-awdlhome-WiFi-disabled.plist` |

只想关掉默认提速、其他不变：在终端运行 `sudo sysctl -w debug.be201_awdl_own_queue=0`，只对这次开机有效。

安装前的完整 EFI 备份在本目录 `EFI-before-install-*`。
