# 1.1.57：修正切换网络时的固件报错

- **1.1.56 的问题：** 提速生效了，但隔空投送之后从手机热点切到路由器时，固件报错（0x20101F49），AWDL 在这次开机里被停用。原因是拆除 AWDL 时，驱动按旧的 TID 15 去撤专用队列，而聚合队列建在 TID 0 上，固件收到了一个撤“不存在的队列”的命令。
- **1.1.57 的修正：** 撤队列时用它实际所在的 TID。其余和 1.1.56 完全一样：默认提速、自动重试建队列、扣住后自动重建、第二信道实验开关（默认关闭），以及构建时按 OpenCore 规则检查驱动文件布局。

## 测试

这次开机 AWDL 已经停用，需要先重启：

1. 重启后，电脑连手机热点，用隔空投送发一个大文件，确认速度还在。
2. 再切到路由器（信道不是 149，最好是 36–48），确认隔空投送和通用控制还能用。这一步就是 1.1.56 出错的地方。
3. 在路由器上开始用隔空投送发一个 3 GB 以上的文件，然后双击“开始信道实验.command”，按提示操作，约 2 分钟。

实验可能让 Wi-Fi 断开十几秒。如果卡死，长按电源键关机再开机，有 panic 文字先拍照。

## 回退

把 EFI/OC 下对应文件复制为 EFI/OC/config.plist，再重启：

| 情况 | 配置 |
|---|---|
| 回到 1.1.56（切网后可能停用 AWDL） | `config-BE201-awdltid-rollback.plist` |
| 保留 1.1.57，关闭全部 AWDL 参数 | `config-BE201-awdltid-off.plist` |
| 只把机型改回 MacPro7,1 | `config-BE201-awdltid-macpro.plist` |
| 禁用这张网卡的 Wi-Fi 驱动 | `config-BE201-awdltid-WiFi-disabled.plist` |

只想关掉默认提速、其他不变：在终端运行 `sudo sysctl -w debug.be201_awdl_own_queue=0`，只对这次开机有效。

安装前的完整 EFI 备份在本目录 `EFI-before-install-*`。
