# 1.1.58：第二信道选对信道

- **1.1.57 的信道实验：** 电脑在路由器 36 信道上时，系统给 AWDL 排的时间表是 `36 0 149 0 0 0 0 0 6 0 149 …`，第 0 段就是路由器的 36。自动选信道只看时间表里第一个 5GHz 信道，于是选成 36（等于路由器信道），判定为“不需要第二信道”。手机始终没有出现在 awdl0 上，所以隔空投送一直“等待中”。
- **1.1.58 的修正：** 自动选信道改为选时间表里不是路由器信道的那个 5GHz 信道（这里是 149）。驱动在每个 AW 周期都更新计数，周围没有设备时，实验工具也能读到当前值。
- **实验工具：** 先打开“自动第二信道 + 按自己时间表开窗口”，再请你开始投送；每段都记录当时的时间表和自动选的信道。
- **其余和 1.1.57 一样：** 默认提速、切换网络修正，第二信道仍是实验开关，默认关闭。

## 测试

1. 重启，电脑连路由器（信道不是 149，最好是 36–48），iPhone 解锁放在旁边，连它自己的网络或蜂窝。
2. 准备一个 3 GB 以上的大文件，先不要发送。
3. 双击“开始信道实验.command”，按回车开始。工具会先测 10 秒基准，然后打开第二信道，再提示你开始投送。
4. 之后测三段：按自己时间表开窗口 30 秒、按手机时间表开窗口 30 秒、不开窗口 20 秒，最后关闭第二信道。
5. 最后回答文件有没有传完，哪一段开始传、哪一段明显变快或卡住。

实验可能让 Wi-Fi 断开十几秒。如果卡死，长按电源键关机再开机，有 panic 文字先拍照。

## 回退

把 EFI/OC 下对应文件复制为 EFI/OC/config.plist，再重启：

| 情况 | 配置 |
|---|---|
| 回到 1.1.57 | `config-BE201-awdlchan2-rollback.plist` |
| 保留 1.1.58，关闭全部 AWDL 参数 | `config-BE201-awdlchan2-off.plist` |
| 只把机型改回 MacPro7,1 | `config-BE201-awdlchan2-macpro.plist` |
| 禁用这张网卡的 Wi-Fi 驱动 | `config-BE201-awdlchan2-WiFi-disabled.plist` |

只想关掉默认提速、其他不变：在终端运行 `sudo sysctl -w debug.be201_awdl_own_queue=0`，只对这次开机有效。

安装前的完整 EFI 备份在本目录 `EFI-before-install-*`。
