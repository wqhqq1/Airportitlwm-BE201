# 1.1.53：查清“对端队列被扣住”

- **1.1.52 的结果：** 专用队列确实跟到了接收方，但放进去的帧一帧都没发出去，被固件扣住了，所以速度没变，聚合也没机会测。
- **这一版的猜测：** 一是第二个 MAC 处在省电状态，在等一个永远不会来的信标；二是 AWDL 链路从没收到过 QoS 参数，也就是每个优先级走哪个发送通道。路由器那条链路这两样都有。
- **这一版的做法：** 两个猜测各对应一个实验开关，实验工具会逐个打开，看哪一步之后帧能发出去，最后再测聚合。
- **都是实验开关：** 默认关闭，重启后恢复关闭。日常行为和 1.1.52 一样。

## 测试

1. 重启，电脑连手机的 5GHz 热点（149 信道），iPhone 解锁放旁边。
2. 准备一个 1 GB 以上的大文件。
3. 双击“开始隔空投送实验.command”，按提示开始发送后按回车。工具会分五段测试，每段约 20 秒。
4. 最后回答文件有没有传完、大约用了多久。

这个实验可能让 Wi-Fi 断开十几秒。如果卡死，长按电源键关机再开机，有 panic 文字先拍照。

## 回退

把 EFI/OC 下对应文件复制为 EFI/OC/config.plist，再重启：

| 情况 | 配置 |
|---|---|
| 回到 1.1.52，关闭全部 AWDL 参数 | `config-BE201-awdlheld-rollback.plist` |
| 保留 1.1.53，关闭全部 AWDL 参数 | `config-BE201-awdlheld-off.plist` |
| 只把机型改回 MacPro7,1 | `config-BE201-awdlheld-macpro.plist` |
| 禁用这张网卡的 Wi-Fi 驱动 | `config-BE201-awdlheld-WiFi-disabled.plist` |

安装前的完整 EFI 备份在本目录 `EFI-before-install-*`。
